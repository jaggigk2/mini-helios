# Mini-Helios capability map

| JD line | Platform capability | KPI you'd report |
| --- | --- | --- |
| Accelerate onboarding and adoption | Self-service API onboarding | Days from request to first call |
| SLA/SLO adherence | Per-service SLOs + error budgets | % of services within error budget |
| Normalize data for real-time decisions | Canonical machine event schema | Event freshness (p95 seconds) |
| APIs as products, reuse | Shared API catalogue (documented, self sign-up) | Teams consuming each shared API (target 10) |
| Event-driven, distributed systems | Self-service event stream (teams subscribe themselves) | Event delivery time p95 < 5 s |
| Observability and incident management | Built-in monitoring & alerting + standard incident process | MTTR < 4 h |
| DevOps, CI/CD, automated quality (TDD/BDD) | Golden-path pipeline template (build, test, deploy) | Lead time commit to live < 1 day |
| AI for developer and business outcomes | Shared AI service with safety checks | Hours saved per engineer per week |
| Modernize legacy systems | Step-by-step migration pattern (old and new side by side) | % of legacy functions migrated |
| Cost and efficiency | Cost visibility per team + scale-to-zero shared compute | Unit cost (€ per connected machine per month) |
